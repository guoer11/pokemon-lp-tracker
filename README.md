# Pokémon LP 計分 PWA

個人使用的 2026–27 Pokémon Asia Championship Series TCG 聯盟賽點數紀錄工具。

## 已實作
- 日期、地點、比賽規格、參加人數、最終名次、LP
- 超級球聯盟賽：依 2026–27 官網公布表格自動計分
- 紀念球聯盟賽：依 2026–27 官網公布表格自動計分
- 高級球／大師球：目前官網詳細 LP 規則尚未公布，先採手動輸入
- 自動計算 LP 最高 8 場（Best Finish Limit）
- Best 8 標記、篩選、刪除
- IndexedDB 本機儲存
- JSON 備份／還原
- PWA，可加入 iPhone 主畫面並離線使用
